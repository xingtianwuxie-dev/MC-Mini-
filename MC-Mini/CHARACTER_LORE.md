## 核心角色

### Notch（人皇）—— MC帝国统治者
- **定位**：团结村庄建国的人皇，垂垂老矣（开局就老）。强人在则爆、亡则碎的悲剧核心。
- **剧情**：封印弟弟 Herobrine → 帝国昌盛千年 → 衰老封印松动 → 魔族复仇 → 发表"人皇口谕"（HJM.30，走出高墙走进伤兵村庄）凝聚帝国 → 击败魔族后自然驾崩（战后老死，非战死）。
- **特性**：rende（人望？）/ old_guard / politically_connected；absolute_monarchist。
- **文风关键**：口谕事件是全文风标杆——"宫门洞开。人皇 Notch 走出了深锁百年的高墙…没有金殿，没有万民山呼，只有烧焦的…"（史官笔法，长段落，克制悲凉）。

### Herobrine（HIM）—— 魔族之主
- **定位**：Notch 之弟，被封印，逃脱回下界复仇。假死失踪（retire_character + missing flag，留 IF 线）。
- **剧情**：下界集结怪物大军（HIM.1 魔族集结→HIM.6 君临主世界）→ 战争 → 战败假死失踪。
- **文风**："黑暗终于被编成军队""被帝国压在史书页脚的阴影，也会有写回正文的一天"——反派也有史诗感，不是单纯邪恶。

### Zimin（籽岷）—— 多玩领袖
- **定位**：穿越者左派代表，duowanism 意识形态，政治顾问（monthly_population + libertarian_socialist_drift）。
- **剧情**：穿越者联盟左派→多玩玩家联盟→红石飞升路线核心。

## 文风基准（写剧情必读）
1. 史官笔法：长段落叙事，第三人称，克制悲凉
2. 重复意象收尾（"后来史官整理案卷时…""把狼烟误作炊烟"）
3. 反派有史诗感（魔族不是单纯邪恶）
4. 觉醒是回光返照——文案表面盛世赞歌，绝不露透支/临终
5. 数字注：HJM.30 人皇口谕 / HJM.32 驾崩 / HJM.36 摄政 / HJM.60-62 连锁负面
