# MC-Mini 剧情纲要

> 按时间顺序的主线剧情 · 2026-08-22 编
> 查单个设定（人物/国家/事件词条）看《设定集.md》，本文只讲故事怎么走。

**一句话**：Notch 建国封印弟弟 Herobrine → 千年腐败、封印松动 → Herobrine 下界复仇 → 帝国败退 → 人皇宣言凝聚 → 击败魔族解放下界 → Notch 驾崩、四方内战 → 多玩红石飞升 → 红石统辖体成立。

**悲剧内核**：强人在则爆，强人亡则碎。战争不是新生，是古老帝国的句号；觉醒不是复兴，是临终前的强光。

---

## 第一幕 · 建国与封印（背景）

人皇 Notch 团结主世界村庄建立 MC 帝国，封印了自己的弟弟——魔神 Herobrine。帝国昌盛千年。

## 第二幕 · 千年衰败（开局，1936）

开局即衰败：Notch 垂垂老矣，封印松动；朝廷派系扭曲内斗（保皇党/穿越者联盟/微软商会）；「承平日久」的军队组织涣散。战前国策三线并进（防御/红石/穿越者），「13 号唱片」事件揭开魔族动向——唱片里录着不该存在的声音。

## 第三幕 · 魔族战争

Herobrine 在下界集结怪物大军（下界要塞 + 洞穴聚落/猪灵堡垒/玄武岩城邦/林地府邸四仆从），向 Notch 复仇。「兄弟归来」后进入 180 天开战倒计时，可以「延后」拖时间，倒计时归零或手动点爆即全面开战。

开局帝国兵败如山倒。

## 第四幕 · 睡狮苏醒

开战满一年，且魔族已占领帝国本土超一成州——人皇 Notch 走出深锁百年的高墙，走进伤兵村庄，发表「人皇口谕」。没有金殿，没有万民山呼。帝国换上「睡狮苏醒」，魔族换上「斗志涣散」。

⚠️ 文案表面全是盛世赞歌——这是回光返照。玩家要到崩盘后才会回味：觉醒不是帝国爆发了，是它在临终前烧出了最后一点强光。

## 第五幕 · 凶猛反攻

战时国策直线反攻：解放村庄 → 名将出山 → 打击下界 → 尊严之刃 → 总动员 → 解放下界。三大党派在战争中愈战愈勇，穿越者的锋刃与村民的骨血共同赢下战争；战争中穿越者联盟内部左右彻底决裂——左派=多玩玩家联盟，右派=网易。

## 第六幕 · 战争落幕

「结束了？」国策收束战争。战后处置三选一：

- **下界行政区方案**：下界要塞改组为帝国附庸「下界行政区」（帝制+总督）；锡兰岛割出建立**封印地**——Herobrine 的封印之处，由他本人名义统治、实为帝国最深的囚徒。
- **和会瓜分**：走正常和平会议吞并魔族。
- **仆从处置**（事件链）：对四仆从国逐一选 温和附庸 / 复仇清算 / 毁灭。

## 第七幕 · 人皇驾崩

战后 Notch 自然老死（不是战死——强人自然衰亡，更悲凉）。Jeb 摄政，朝廷矛盾进入发酵期，「睡狮苏醒」反转成扭曲反噬。

## 第八幕 · 帝国分裂

人皇逝世起 200 天内战倒计时（「延揽人心备战」可续命 120 天，到期或手动点爆）。HJM_split.1 四选一：保皇（留 HJM）/ 多玩（DWF）/ 网易（NTE）/ 微软（MST）——帝国彻底碎裂，四方内战爆发，超事件「**冠冕坠地**」奏响。

## 第九幕 · 四方内战与红石飞升

内战主线在多玩穿越者联邦（西北六州）。权力平衡「协调派 ⇄ 解放派」是政治主擂台；走到极端段位解锁隐藏道路：

- **协调极端 → 红石技官线**（工业）：红岩苏醒 → 雷石东接管 → 戈壁巨型电路 → 四姐妹上线 → 「MC 红石智能统辖体」
- **解放极端 → 共同体线**（军事）：公社大联合 → 全民皆兵 → 解放军整编 → 「人类命运共同体」

红石终端的演进贯穿始终：**0 号机**（内战初期基础服务 AI）→ **1.0 雷石东**（与网易决战前，戈壁巨型电路接管最高权力中枢，口号「用技术领导政权」）→ **2.0 四姐妹**（统一后四系统全面接入）→ 最后一道人类批文盖上「已归档」，**MC 红石智能统辖体**成立。

党争、派系、拉扯——统辖体把这根拔河绳收进了仓库。从此西北的每一盏灯，亮与不亮都不再需要理由。

内战终局：四方继承者仅存其一，超事件「**尘埃落定**」奏响——与开战的「烽烟既起」首尾呼应。无论站着的是谁，都不再是那个古老帝国了。
